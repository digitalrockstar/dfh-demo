Connector: CSV drop Live

Four connector types feed the same checks: drop <dataset>__name.csv into the drop folder, POST to /api/ingest/<dataset> (webhook, off until a token is set), REST pull and SQLite read (both off until the operator configures sources). Each file is landed once (sha256), checked row by row, good rows go to staging, bad rows are kept with a reason. Staged sales feed Sales, Executive MIS, Growth and the Insight Engine; staged stock feeds Inventory and Executive MIS; other pages still read the seed.

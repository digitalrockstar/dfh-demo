# SKILLS and working rules for the assistant

- token-optimization: use tokens frugally, no running commentary, work locally, report with a summary when the task is done.
- pdf (reportlab): the plan PDF is built by docs/build_book.py. No Unicode sub or superscripts; Helvetica has no rupee symbol, write Rs or INR.
- apple-design (docs/skills/apple-design.md): applied to frontend motion, materials (glass) and typography.
- Writing rules for Akshay: brutally honest, confident, assertive, humble. No em dashes, no arrows, no contrastive constructions, no filler, no AI-sounding phrasing, plain upper-ordinary vocabulary.
- Dev rules: Python first, local build and test before reporting, module by module, tests per module, keep money in paise, quantities as integers in base unit (grams for loose, units for packed).
- Security: never write credentials to files or commits. Tokens are used only through environment variables for the push and are removed from git config afterwards.
